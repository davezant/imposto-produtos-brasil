###### Essa projeto é colaborativo e tem como motivo criar uma base descomplicada para projetos de pequeno e médio porte para pesquisar sobre o imposto de cada produto no Brasil.

### Sobre o projeto

Este projeto reúne, em formato simples e aberto, os impostos incidentes sobre produtos vendidos no Brasil. O país já ultrapassou a marca de R$ 3 bilhões em arrecadação — um número que raramente é traduzido para o consumidor final de forma clara e acessível.

A proposta é descomplicar essa informação, tornando-a fácil de consultar, reutilizar e auditar.

### Objetivo

Fornecer dados fiscais simplificados para:

- Projetos de pequeno e médio porte que precisem de uma base tributária confiável;
- Sistemas educacionais voltados ao ensino de economia e cidadania fiscal;
- Ferramentas de transparência tributária para o consumidor.

Além do uso técnico, o projeto busca ampliar a percepção da população sobre a carga de impostos embutida no consumo diário, e incentivar o questionamento aos responsáveis pela gestão desses recursos.

### Quem pode contribuir

Não é necessário saber programar para colaborar. O projeto depende de contribuições diversas:

- **Pesquisa**: levantamento de produtos e alíquotas ainda não catalogados.
- **Revisão**: validação de dados já existentes com base em fontes oficiais.
- **Divulgação**: dar visibilidade ao projeto e traduzir dados técnicos em linguagem acessível.
- **Desenvolvimento**: automação de coleta, validação e criação de ferramentas a partir das planilhas.

### Estrutura dos dados

Os dados são mantidos em CSV para garantir acesso simples, inclusive por quem não tem conhecimento técnico (Excel, Google Sheets, LibreOffice).

Cada registro deve conter, obrigatoriamente, a fonte oficial que comprova o dado.

### Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração.
3. Adicione ou edite os registros, mantendo a estrutura da tabela.
4. Abra um Pull Request detalhando as alterações.
5. Inclua a fonte oficial dos dados (Diário Oficial da União, normativas da Receita Federal, etc.).

**Nenhuma alteração é aceita sem comprovação documental da fonte.** Essa exigência é o que sustenta a confiabilidade do projeto.

### Por que isso importa

Dados fiscais acessíveis ampliam a capacidade de fiscalização social. Quanto mais pessoas entendem quanto pagam de imposto, mais informado fica o debate público sobre arrecadação e uso dos recursos.
