# Introdução

Se você está vendo essa introdução a documentação, possivelmente você se interessou pelo projeto então obrigado e seja bem-vindo. Primeiramente esqueça política, objetivo é desse projeto é esclarecer a nossa carga tributária para que seja de acessivel visualização, em oposição aos sistemas de transparência brasileiros que fragmentam a informação em inúmeras partes. O projeto é open-source e é aberto a Pull Requests desde que você cumpra as regras.

### Estrutura dos dados

Os dados são mantidos em CSV para garantir acesso simples, inclusive por quem não tem conhecimento técnico (Excel, Google Sheets, LibreOffice).
A estrutura das planilhas serve para facilitar a modificação do código, de forma que seja um modelo de IA ou pessoas com pouco conhecimento técnico de tecnologia possam mudar informações caso haja.
